# JobHunter-AI

Dossier de candidature multilingue pour Ibrahima Sow.

## Contenu

- `cv/` : CV en français, anglais et allemand
- `cover_letters/` : lettres de motivation
- `jobs/` : suivi des offres
- `automation/` : automatisation de recherche et candidature
- `database/` : stockage local
- `config/` : configuration du projet
- `docs/` : documentation
- `site/` : interface locale avec photo et aperçu du dossier

## Site local

```bash
cd site
npm ci
npm start
```

Ouvrir `http://localhost:4173`. L’interface et toutes les options utilisateur sont en français.

Le détail du déploiement Docker, Railway ou Render est disponible dans [docs/deploiement.md](docs/deploiement.md).
